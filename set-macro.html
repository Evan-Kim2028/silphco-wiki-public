Read this first

Think of each set as a hill. Some hills are being climbed right now by lots of people at once — those prices already jumped. Some hills are being walked up slowly. Some were climbed years ago, everyone left, and a few people are just coming back.

You usually want the slow, steady hill: still going up, but not so fast that you are paying for a move that already happened.

Still asleep
